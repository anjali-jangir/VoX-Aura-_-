⚙ Quick Setup

  1. No API key needed to start — free neural voices work out of the box.
  2. Install & run: npm install then npm start — open http://localhost:3000.
  3. Want premium ElevenLabs voices? Set TTS_PROVIDER=elevenlabs in .env, add your key to ELEVENLABS_API_KEY, and make sure the account has credits.
  4. Voice IDs can be changed in the VOICES array in script.js (edge = Edge neural voice, gl = Google language, id = ElevenLabs ID).

On static hosts (GitHub Pages, Netlify) the site calls the free voices directly from your browser — no backend needed. Full guide in README.md.
